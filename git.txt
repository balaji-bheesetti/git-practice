discarding changes:
-- git restore --staged <filename> (for staged do this forst then do then next command)
-- git restore <filename>

clean untracked files:
-- git clean -n (to list untacked files)
-- git clean -f (to remove untracked files)

git stash: is used to temporarily save uncommitted changes without creating new commit.
-- git stash (then move to another branch and come back again. then)
-- git stash -u (stash even new files also)
-- git stash pop
-- git stash list
-- git stash pop stash@{index}
-- git stash apply stash@{index} -> used to apply stash and save the stash which can be used for another branch.
-- git stash drop satsh@{index} -> to remove a stash

Amending means modifying the most recent commit insted of creating new commit
-- git commit --amend -m "message"
-- git commit --amend --no-edit (to add new changes or files without creating new commit)

Revert is used to undo changes made by previous commit without deleting that commit from history.
-- git revert <hashcode> 

Reset is used to move local branch backwards
-- git reset --soft <hashcode> (reset commit but keep file changes in staging area)
-- git reset --mixed <hashcode> (reset commit but keep file changes but not in staging area)
-- git reset --hard <hashcode> (reset commit and files changes too)

Reflog is like history of git movements in local.
-- git reflog

diff is used to compare changes between files, commits, branches, staging area.
-- git diff
-- git diff --staged
-- git diff --staged <filename>
-- git diff <another branch>
